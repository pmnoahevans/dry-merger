# dry-merger

Platform engineer · Zig and bare metal

练手项目


## 用法

```bash
cat data.txt | node index.js
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/pmnoahevans/dry-merger.git
cd dry-merger
npm install
```
